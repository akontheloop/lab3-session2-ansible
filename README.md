# Lab 3 - Session 2 - Ansible

## Objective
Configure infrastructure and automate application configuration using Ansible playbooks.

## Tools Used
- Ansible
- YAML
- macOS Terminal

## Project Files
- inventory: Defines the target host
- playbook.yml: Automates application deployment

## Tasks Performed
1. Created an Ansible inventory.
2. Created an Ansible playbook.
3. Created an application directory.
4. Deployed an HTML webpage.
5. Verified application deployment.
6. Tested idempotency.

## Execution
ansible-playbook -i inventory playbook.yml

## Result
Successfully automated application deployment using Ansible.
